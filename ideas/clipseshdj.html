About Clip Sesh DJ

Clip Sesh DJ

A local-first, two-deck browser DJ workstation. Audio decoding, waveform/tempo analysis, playback, effects, MIDI control, and recording happen on this device.

Core engine

Dual decks, tempo control, approximate pitch lock, beat/phase sync, quantized loops, cues, scratching, EQ, filters, crossfader, and master limiting.

Effects

Delay, echo, reverb, dub echo, filter, flanger, phaser, spiral, trans/gate, distortion, bit crush, and roll. Effects are isolated in the embedded Effects / DSP script module near the end of this page.

Control

Mouse, touch, keyboard, Web MIDI, absolute and relative encoders, and persisted custom mappings.

Privacy

Local files stay local. Google Drive imports request only public resources that the user chooses.

Single-file build: open this page with “View Source” to inspect the seven separately labeled embedded script modules and the embedded stylesheet.

Independent project. Clip Sesh DJ is not affiliated with AlphaTheta, Pioneer DJ, or rekordbox. Use only audio you are authorized to access, play, and record.
